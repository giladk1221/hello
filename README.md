# Hello World Python App

A collection of creative Hello World functions in Python, created as part of KOKO-11.

## Functions

| Function | Description |
|---|---|
| `hello_world()` | Basic hello world |
| `hello_named(name)` | Personalized greeting |
| `hello_uppercase()` | Uppercase hello world |
| `hello_lowercase()` | Lowercase hello world |
| `hello_reverse()` | Reversed hello world |
| `hello_repeat(times)` | Repeated hello world |
| `hello_timestamp()` | Hello world with timestamp |
| `hello_random_language()` | Random language greeting |
| `hello_ascii_art()` | ASCII art hello world |
| `hello_bordered()` | Bordered hello world |
| `hello_countdown(seconds)` | Hello world after countdown |
| `hello_custom(greeting, target, punctuation)` | Fully customizable greeting |
| `hello_multiline()` | Multi-line formatted greeting |
| `hello_char_by_char()` | Character-by-character output |
| `hello_leetspeak()` | Leetspeak hello world |
| `hello_alternating_case()` | Alternating case hello world |
| `hello_pig_latin()` | Pig Latin hello world |
| `hello_emoji()` | Emoji hello world |

## Usage

```bash
python hello_world.py
```

To use individual functions:

```python
from hello_world import hello_named, hello_bordered

hello_named("Alice")
hello_bordered()
```
