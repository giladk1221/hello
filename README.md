# Hello World Python Application

A Python application featuring multiple variations of "Hello, World!" greetings.

## Functions

| Function | Description |
|---|---|
| `hello_world()` | Basic "Hello, World!" message |
| `hello_named(name)` | Personalized greeting with a given name |
| `hello_uppercase()` | Hello world in UPPERCASE |
| `hello_lowercase()` | Hello world in lowercase |
| `hello_reverse()` | Hello world printed in reverse |
| `hello_repeat(count)` | Repeat hello world a specified number of times |
| `hello_timestamp()` | Hello world with the current date and time |
| `hello_random_language()` | Hello world in a randomly selected language |
| `hello_ascii_art()` | Hello world displayed as ASCII art |
| `hello_bordered()` | Hello world inside a decorative border |
| `hello_countdown(seconds)` | Countdown before printing hello world |
| `hello_custom(greeting, target, punctuation)` | Fully customizable greeting |
| `hello_multiline()` | Hello world in a multiline decorative box |

## Usage

Run all greeting functions:

```bash
python hello_world.py
```

Import and use individual functions:

```python
from hello_world import hello_named, hello_custom

hello_named("Alice")
hello_custom("Hi", "Team", "!")
```

## Requirements

- Python 3.6+
