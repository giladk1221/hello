# Hello World Python Application

**Jira Ticket:** SCRUM-1221

A Python application showcasing multiple variations of the classic "Hello, World!" program.

## Requirements

- Python 3.6+

## Usage

Run the application:

```bash
python hello_world.py
```

## Functions

| Function | Description |
|---|---|
| `hello_world()` | Prints a basic "Hello, World!" message |
| `hello_name(name)` | Prints a personalized greeting |
| `hello_multilingual(language)` | Prints hello in 13 different languages |
| `hello_uppercase()` | Prints hello world in uppercase |
| `hello_lowercase()` | Prints hello world in lowercase |
| `hello_reverse()` | Prints hello world reversed |
| `hello_repeated(times)` | Prints hello world multiple times |
| `hello_with_timestamp()` | Prints hello with the current timestamp |
| `hello_ascii_art()` | Prints hello world as ASCII art |
| `hello_random_greeting()` | Prints a random hello variation |
| `hello_bordered()` | Prints hello inside a decorative border |
| `hello_countdown(start)` | Counts down then prints hello |
| `hello_letter_by_letter()` | Prints hello one letter at a time |

## Supported Languages

English, Spanish, French, German, Italian, Portuguese, Japanese, Chinese, Korean, Russian, Arabic, Hindi, Hebrew

## Example

```python
from hello_world import hello_name, hello_multilingual

hello_name("Alice")       # Output: Hello, Alice!
hello_multilingual("french")  # Output: Bonjour, le Monde!
```
